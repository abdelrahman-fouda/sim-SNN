# sim-SNN

This repository was the initial planning workspace for integrating **spiking neural networks (SNNs)** with **SKRL reinforcement learning** in NVIDIA Isaac Lab.

The completed implementation, reproducible experiments, tests, figures, videos, and technical report now live in:

## [SNN-RL-IsaacLab](https://github.com/abdelrahman-fouda/SNN-RL-IsaacLab)

The final project includes:

- snnTorch policy and value networks integrated with SKRL PPO
- GPU-parallel quadcopter training in Isaac Lab
- matched SNN-versus-MLP experiments
- spike-sparsity and smooth-control studies
- automated tests and documented reproduction steps

This repository is retained as a record of the original project scaffold. For evaluation or reuse, please use the completed repository above.
